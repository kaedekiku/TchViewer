TchViewer 使い方

Twitch のチャットと、5ch・したらば・JPNKN のレスをまとめて OBS に表示し、読み上げるソフトです。
掲示板のレスは、LiveFake で「配信ホワイトリスト」に入れた人（自分宛て）のものだけを表示します。

1. 必要なもの

  • Windows 10 / 11（64bit）
  • Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています。Windows 10 でも多くの場合入っています）
  • OBS Studio（表示する場合）
  • LiveFake（掲示板のレスを表示する場合）… https://github.com/kaedekiku/LiveFakeTauri2
  • 読み上げを使う場合は、棒読みちゃん・VOICEVOX のどちらか（Windows 標準の音声だけで使う場合は不要）

2. はじめかた

  1. ダウンロードした zip ファイルを、好きな場所に展開します（例: D:\Tools\TchViewer）。
    インストールは不要です。
  2. 展開したフォルダの中の TchViewer.exe をダブルクリックします。
  3. TchViewer の画面が開いたら準備完了です。画面の左にメニューが並んでいます。
「Windows によって PC が保護されました」と表示されたとき
詳細情報 を押してから 実行 を押すと起動できます（電子署名の無いソフトに表示される確認です）。

TchViewer を終了するときは、ウィンドウの右上の × を押します。設定は自動で保存され、次に起動したときも同じ設定・同じウィンドウの位置で開きます。

3. Twitch とスレッドをつなぐ

  1. 左のメニューの 接続 を押します。
  2. Twitchチャンネル に、表示したいチャンネルの ID か URL を入れます（例: https://www.twitch.tv/example）。ログインは不要です。
  3. スレッドURL に、5ch・したらば・JPNKN のスレッドの URL を入れます。複数ある場合は1行に1つずつ入れます。
  4. 保存して接続 を押します。

画面の上に、接続先ごとのランプが表示されます。緑=正常、黄=接続中、赤=エラーです。

  • 掲示板の巡回間隔: 掲示板を見に行く間隔です（10〜300秒、普段は 15 秒のままで大丈夫です）。
  • Twitch のバッジ画像を取得する: サブスクなどのバッジを表示します。Twitch の公式ではない方法で取得しているため、表示がおかしいときはオフにしてください。
  • スレッドが 1000 まで埋まったら、次スレの URL に差し替えて 保存して接続 を押してください。

4. LiveFake と連携する（掲示板のレスを表示する）

TchViewer は、掲示板のレスのうち LiveFake の「配信ホワイトリスト」に入っている ID のレスだけ を表示・読み上げします。ホワイトリストが空のときや、連携していないときは、掲示板のレスは1件も表示されません。

  1. LiveFake で、設定 > TchViewer連携 の「TCVホワイトリスト」をオンにします。
  2. TchViewer の左のメニューの LiveFake連携 を押します。
  3. フォルダを選ぶ を押し、LiveFake の data フォルダを選びます（LiveFake の 設定 > TchViewer連携 に場所が表示されています）。
  4. LiveFake でレスの ID をホワイトリストに追加すると、1〜2秒で TchViewer の「有効なID」に表示されます。
ホワイトリストはその日だけ有効です（5ch の ID は日付が変わると変わるため）。日本時間の 0 時を過ぎると、前の日の一覧は自動で使われなくなります。

5. OBS に表示する

  1. TchViewer の左のメニューの 表示（OBS） を押し、OBS に追加するURL の コピー を押します。
    （通常は http://localhost:11280/overlay.html です）
  2. OBS の「ソース」の ＋ を押し、ブラウザ を選びます。
  3. 名前を付けて OK を押し、URL にコピーした URL を貼り付けます。
  4. 幅と高さを設定します（例: 幅 600 / 高さ 800）。OK を押すと表示されます。
OBS に表示するには、TchViewer を起動しておく必要があります。OBS を先に起動していた場合は、TchViewer を起動すると自動でつながります。

6. 見た目を変える・シーンごとに使い分ける

見た目を変える

表示（OBS） で、文字の大きさ・フォント・色・背景・表示する項目などを変えられます。変えるとすぐに OBS とプレビューに反映されます。

  • フォントは、パソコンに入っているフォントから選べます（入力すると候補が出ます）。
  • 読みにくい名前の色を自動で調整する をオンにすると、背景に対して見えにくい Twitch の名前の色だけを、自動で明るく（または暗く）します。

シーンごとに別の見た目を使う（レイアウト）

  1. 表示（OBS） の レイアウト 欄に新しい名前（例: ゲーム画面用）を入れ、新規作成 か 複製して作成 を押します。
  2. レイアウトを選んだ状態で見た目を変えると、そのレイアウトにだけ保存されます。
  3. OBS に追加するURL は、選んでいるレイアウト用の URL に変わります（例: …/overlay.html?layout=ゲーム画面用）。OBS のシーンごとに、使いたいレイアウトの URL をブラウザソースに設定してください。

追加CSS（さらに細かく変えたい人向け）

レイアウトごとに CSS を追加できます。表示（OBS） の下にある 追加CSS 欄に貼り付けて CSSを保存して反映 を押します。

例1: 名前の右に本文を続ける（チャット欄と同じ並び）

.msg .meta { display: inline; margin-right: .6em; }
.msg .text { display: inline; }

例2: 名前の列と本文の列を分ける（本文は本文の列の中で折り返す）

.msg .body { display: flex; align-items: baseline; gap: .6em; flex: 1; }
.msg .meta { flex: none; white-space: nowrap; max-width: 45%; overflow: hidden; text-overflow: ellipsis; }
.msg .text { flex: 1; min-width: 0; }

例3: Twitch のチャットを表示しない

.msg.twitch { display: none; }

OBS のソースごとに一部だけ変える

URL の後ろに付けると、そのソースだけ設定を上書きできます。

付けるもの意味
max=10表示する件数
fade=3030秒で消す
size=28文字の大きさ
top=1新しいものを上に並べる
hide=twitchTwitch を表示しない（5ch / shitaraba / jpnkn も指定可。複数はカンマ区切り）

例: http://localhost:11280/overlay.html?max=10&hide=twitch（URL に ? が既にあるときは & でつなぎます）

7. 読み上げ

  1. 読み上げ を押し、新着コメントを読み上げる をオンにします。
  2. 読み上げエンジン を選びます。
  3. テスト読み上げ で確認できます。止めたいときは 読み上げを止める を押します。
エンジン準備
棒読みちゃん棒読みちゃんを起動し、「その他」→「アプリケーション連携」で TCP サーバー（ポート 50001）を有効にします。声や速さは棒読みちゃん側の設定で読みます。
SAPIWindows に入っている音声で読みます。一覧を読み込む で声を選べます。準備は不要です。
VOICEVOXVOICEVOX を起動しておきます。一覧を読み込む で話者を選べます。
  • 掲示板のレスは「レス123番さん」「したらば123番さん」「ジャパンくん123番さん」のように番号を付けて読みます。
  • URL は読みません（YouTube の URL だけ「ユーチューブ」と読みます）。
  • 読み上げるソース で、Twitch・5ch・したらば・JPNKN ごとに読む／読まないを選べます。
  • LiveFake でも読み上げている場合は、同じレスを2回読むことになるので、どちらか一方だけで読む設定にしてください。

8. NGワード

NGワード に、表示・読み上げしたくない言葉を1行に1つずつ入れます（5ch・したらば・JPNKN のレスが対象です）。入力するとすぐに保存され、次に届いたレスから効きます。

  • 大文字・小文字は区別しません。
  • / で囲むと正規表現として使えます（例: /^w+$/ … 「w」だけのレス）。
  • ホワイトリストに入っている人のレスでも、NGワードに当たれば表示しません。

9. ビュワーと状態の確認

  • ビュワー には、OBS に表示されるのと同じコメントが流れます。上のボタンで Twitch・5ch などを絞り込んだり、言葉で検索したりできます。各コメントの 読む でもう一度読み上げ、コピー で本文をコピーできます。
  • 状態 では、接続先ごとに「届いた件数」「表示した件数」「ホワイトリスト外で表示しなかった件数」「NGワードで表示しなかった件数」が分かります。掲示板のレスが表示されないときは、まずここを確認してください。
  • 情報 では、画面のテーマ（Windows に合わせる／ライト／ダーク）を切り替えられます。

10. 困ったとき

掲示板のレスが OBS に表示されない
状態 を開いて確認してください。
  • 「受信」が増えていない → スレッドの URL が正しいか、スレが埋まっていないかを確認します。
  • 「ホワイトリスト外」が増えている → その人の ID が LiveFake のホワイトリストに入っていません。LiveFake連携 の「有効なID」も確認してください。
  • 「NG」が増えている → NGワードに当たっています。
なお、表示されるのは TchViewer を起動した後に届いたレスです。それより前のレスはさかのぼって表示しません。
「ポート 11280 を開けません」と表示されて起動しない
TchViewer がすでに起動しています。タスクバーを確認してください。
OBS に何も表示されない
TchViewer が起動しているか、ブラウザソースの URL が正しいかを確認してください。表示（OBS） の テストコメント を押すと、表示を確かめられます。
Twitch のバッジが表示されない・おかしい
Twitch 側の変更で取得できなくなっている可能性があります。接続 の「Twitch のバッジ画像を取得する」をオフにしてください。
読み上げされない
テスト読み上げ で確認してください。棒読みちゃん・VOICEVOX は起動している必要があります。エラーは 状態 のログに表示されます。
不具合を報告したい
data フォルダの tchviewer.log（今回の起動分）と tchviewer.prev.log（前回の起動分）を添えてください。

11. データの場所と削除

設定などのデータは、すべて TchViewer.exe と同じフォルダの data フォルダに保存されます。Windows の AppData やレジストリには保存しません。

ファイル・フォルダ内容
config.json設定
layouts\レイアウト（見た目の設定と追加CSS。メモ帳で編集することもできます）
window.jsonウィンドウの位置と大きさ
badges-cache.jsonTwitch バッジの一覧（取得できなかったときの予備）
tchviewer.log / tchviewer.prev.log動作の記録（今回の起動分 / 前回の起動分）
webview\画面表示の作業データ

別のパソコンへ移すときは、フォルダごとコピーしてください。
削除するときは、TchViewer を終了してからフォルダごと削除してください。ほかの場所には何も残りません。
