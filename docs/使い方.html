TchViewer 使い方

Twitch のチャットと、5ch・したらば・JPNKN のレスをまとめて OBS に表示し、読み上げるソフトです。
掲示板のレスは、ホワイトリストに入れた人（自分宛て）のものだけを表示し、それ以外は「レス123番さん」と番号だけ読み上げます。

1. 必要なもの

  • Windows 10 / 11（64bit）
  • Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています。Windows 10 でも多くの場合入っています）
  • OBS Studio（表示する場合）
  • LiveFake（掲示板のレスを表示する場合）… https://github.com/kaedekiku/LiveFakeTauri2
  • 読み上げを使う場合は、棒読みちゃん・VOICEVOX のどちらか（Windows 標準の音声だけで使う場合は不要）

2. はじめかた

  1. ダウンロードした zip ファイルを、好きな場所に展開します（例: D:\Tools\TchViewer）。
    インストールは不要です。
  2. 展開したフォルダの中の TchViewer.exe をダブルクリックします。
  3. TchViewer の画面が開いたら準備完了です。画面の左にメニューが並んでいます。
「Windows によって PC が保護されました」と表示されたとき
詳細情報 を押してから 実行 を押すと起動できます（電子署名の無いソフトに表示される確認です）。

TchViewer を終了するときは、ウィンドウの右上の × を押します。設定は自動で保存され、次に起動したときも同じ設定・同じウィンドウの位置で開きます。

3. Twitch とスレッドをつなぐ

  1. 左のメニューの 接続 を押します。
  2. Twitch チャンネル の欄に、チャンネルの ID か URL（例: https://www.twitch.tv/example）を入れて Enter を押します。ログインは不要です。外すときは × を押します。
  3. 監視するスレッド の欄に、5ch・したらば・JPNKN のスレッドの URL を貼り付けます。貼り付けるとすぐに確認して一覧に追加されます（複数行もまとめて追加できます）。

一覧の各行には、スレタイ・接続の状態（緑=正常、黄=接続中、赤=エラー）・レス数（○/1000）が出ます。行はドラッグで並べ替えられ、タブで開く でスレタブに、ブラウザで開く で普段のブラウザに開けます。

  • 詳細設定: 監視するスレを見に行く間隔（10〜300秒、普段は 15 秒のままで大丈夫です）など。スレタブの更新間隔は スレ の上の欄で別に決めます。
  • バッジ画像を取得する: サブスクなどのバッジを表示します。Twitch の公式ではない方法で取得しているため、表示がおかしいときはオフにしてください。
  • スレッドが 1000 まで埋まったら、次スレの URL を追加して、古いスレは削除してください。

4. ホワイトリスト（自分宛てのレス）

監視しているスレのレスは、次のように扱われます。

レス扱い
ホワイトリストに入っている IDOBS に表示し、本文まで読み上げます
ホワイトリストに無い IDOBS には出さず、「レス123番さん」と番号だけ読み上げます（「読み上げ」で変更できます）。ビュワーの下の スレの最新レス の欄に出ます
NG に当たったもの表示も読み上げもしません

ホワイトリストに入れる方法

  • ビュワーの下の スレの最新レス で、気になったレスの 入れる を押す（「今読んでいるレス」は色付きで示されます。入れた ID には WL の印が付き、外す で外せます）
  • スレ のタブで、レス番号の横の WL を押す（入っている ID は WL済 になり、押すと外せます）。ID をクリックして出るメニューからも入れられます
  • 入れた直後に出るお知らせの 取り消す で、すぐ外せます
  • ホワイトリスト の欄に ID を入れて Enter
  • 【試験的】ホワイトリスト の 自動追加 をオンにして登録ワードを入れると、そのワードを含むレスの ID を自動で入れます（1日の上限は既定20件・最大100件）。ワードを知っている人なら誰でも入れるので、推測されにくい言葉にしてください
ホワイトリストはその日だけ有効です（5ch の ID は日付が変わると変わるため）。日本時間の 0 時を過ぎると空になります。一覧から 外す を押した ID は、その日のうちは自動では入れ直しません。

LiveFake の配信ホワイトリストも使う（任意）

  1. LiveFake で、設定 > TchViewer連携 の「TCVホワイトリスト」をオンにします。
  2. TchViewer の ホワイトリスト で フォルダを選ぶ を押し、LiveFake の data フォルダを選びます。
  3. LiveFake で ID を追加すると、1〜2秒で TchViewer にも反映されます（読み取りだけです）。

5. OBS に表示する

  1. TchViewer の左のメニューの 表示（OBS） を押し、OBS に追加するURL の コピー を押します。
    （通常は http://localhost:11280/overlay.html です）
  2. OBS の「ソース」の ＋ を押し、ブラウザ を選びます。
  3. 名前を付けて OK を押し、URL にコピーした URL を貼り付けます。
  4. 幅と高さを設定します（例: 幅 600 / 高さ 800）。OK を押すと表示されます。
OBS に表示するには、TchViewer を起動しておく必要があります。OBS を先に起動していた場合は、TchViewer を起動すると自動でつながります。

6. 見た目を変える・シーンごとに使い分ける

見た目を変える

表示（OBS） で、文字の大きさ・フォント・色・背景・表示する項目などを変えられます。変えるとすぐに OBS とプレビューに反映されます。

  • フォントは、パソコンに入っているフォントから選べます（入力すると候補が出ます）。
  • 読みにくい名前の色を自動で調整する をオンにすると、背景に対して見えにくい Twitch の名前の色だけを、自動で明るく（または暗く）します。

シーンごとに別の見た目を使う（レイアウト）

  1. 表示（OBS） の レイアウト 欄に新しい名前（例: ゲーム画面用）を入れ、新規作成 か 複製して作成 を押します。
  2. レイアウトを選んだ状態で見た目を変えると、そのレイアウトにだけ保存されます。
  3. OBS に追加するURL は、選んでいるレイアウト用の URL に変わります（例: …/overlay.html?layout=ゲーム画面用）。OBS のシーンごとに、使いたいレイアウトの URL をブラウザソースに設定してください。

追加CSS（さらに細かく変えたい人向け）

レイアウトごとに CSS を追加できます。表示（OBS） の下にある 追加CSS 欄に貼り付けて CSSを保存して反映 を押します。

例1: 名前の右に本文を続ける（チャット欄と同じ並び）

.msg .meta { display: inline; margin-right: .6em; }
.msg .text { display: inline; }

例2: 名前の列と本文の列を分ける（本文は本文の列の中で折り返す）

.msg .body { display: flex; align-items: baseline; gap: .6em; flex: 1; }
.msg .meta { flex: none; white-space: nowrap; max-width: 45%; overflow: hidden; text-overflow: ellipsis; }
.msg .text { flex: 1; min-width: 0; }

例3: Twitch のチャットを表示しない

.msg.twitch { display: none; }

OBS のソースごとに一部だけ変える

URL の後ろに付けると、そのソースだけ設定を上書きできます。

付けるもの意味
max=10表示する件数
fade=3030秒で消す
size=28文字の大きさ
top=1新しいものを上に並べる
hide=twitchTwitch を表示しない（5ch / shitaraba / jpnkn も指定可。複数はカンマ区切り）

例: http://localhost:11280/overlay.html?max=10&hide=twitch（URL に ? が既にあるときは & でつなぎます）

7. 読み上げ

  1. 読み上げ を押し、新着コメントを読み上げる をオンにします。
  2. 読み上げエンジン を選びます。
  3. テスト読み上げ で確認できます。止めたいときは 読み上げを止める を押します。
エンジン準備
棒読みちゃん棒読みちゃんを起動し、「その他」→「アプリケーション連携」で TCP サーバー（ポート 50001）を有効にします。速度（50〜300）・音程（50〜200）・音量（0〜100）・声質（女性1〜機械2）を TchViewer で決められます。Twitch のスタンプは、スタンプ名（例: Kappa）をそのまま送るので、棒読みちゃんの「教育」で好きな読み方に置き換えられます（「読み上げ」で「読まない」にもできます）。同じスタンプの連打は、1件につき決めた数（1〜100個、既定3個）まで読みます。「棒読みちゃんの設定」にチェックを入れた項目は、棒読みちゃん側の設定で読みます（抑揚は変えられません）。
SAPIWindows に入っている音声で読みます。一覧を読み込む で声を選べます。準備は不要です。
VOICEVOXVOICEVOX を起動しておきます。一覧を読み込む で話者を選べます。
  • 掲示板のレスは「レス123番さん」「したらば123番さん」「ジャパンくん123番さん」のように番号を付けて読みます。
  • ホワイトリストに無い ID のレスの読み方は、番号だけ読む（既定）・通知音だけ・本文まで・読まない から選べます。
  • 掲示板の URL は読みません（YouTube の URL だけ「ユーチューブ」と読みます）。Twitch のチャットの URL は「URL省略」と読みます。
  • 「最大文字数」を超えた分は読まず、「、以下省略」と読みます。
  • 読み上げるソース で、Twitch・5ch・したらば・JPNKN ごとに読む／読まないを選べます。
  • LiveFake でも読み上げている場合は、同じレスを2回読むことになるので、LiveFake 側の読み上げはオフにしてください。

8. NG と Twitch イベント

NG

NG で、表示・読み上げしたくないレスを指定できます（5ch・したらば・JPNKN が対象です）。

  • 種類: ワード（本文）・名前・ID
  • 処理: 通常あぼーん（スレタブで「あぼーん」と表示）／透明あぼーん（スレタブでも出さない）。どちらも OBS には出ず、読み上げません
  • 範囲: 全体／このスレだけ
  • ワードと名前は、大文字・小文字を区別しません。/ で囲むと正規表現として使えます（例: /^w+$/ … 「w」だけのレス）
  • スレタブで文字を選んで右クリック、または選んだ文字をドラッグして下に出る枠に落とすと、すぐに NG ワードに追加できます

Twitch イベント

サブスク・継続サブスク・ギフト・まとめてギフト・ビッツ・レイド・連続視聴・チャンネルポイントなどを、チャット欄に目立つカードで流して読み上げます。Twitch イベント で、種類ごとに チャットに流す・読み上げる・読み上げる文 を変えられます（テスト で確認できます）。

読み上げる文には {name}（名前）{months}（月数）{count}（個数・回数）{bits}（ビッツ）{viewers}（人数）{recipient}（ギフトの相手）{reward}（報酬名）{message}（メッセージ）を差し込めます。

入力の無いチャンネルポイント報酬・フォローも表示する（Twitch ログイン）

  1. Twitch イベント の Twitch にログイン を押します。
  2. ブラウザで Twitch のページが開き、TchViewer に8文字ほどのコードが表示されます。ページにコードを入力し、配信者本人のアカウントで 許可 を押します。
  3. 「ログイン中・受信中」になれば完了です。
求める許可は読み取りだけです（チャンネルポイントの引き換え・フォロワー）。ログイン情報は Windows の機能で暗号化して data フォルダに保存されます。30日間使わないとログインし直しになります。別のパソコンにフォルダをコピーした場合もログインし直しが必要です。ログアウト で Twitch 側の許可も取り消せます。

9. ビュワー・スレタブ・状態

  • ビュワー には、OBS に表示されるのと同じコメントが流れます。上のボタンで Twitch・5ch などを絞り込めます。各コメントの 読む でもう一度読み上げ、コピー で本文をコピーできます。最新レス欄 のオン・オフで、下の欄を出すかどうかを選べます。
  • ビュワーの下の スレの最新レス には、開いているスレタブに新しく届いたレスと、監視するスレで番号だけ読んだレスが流れます（タブを開いたときに読み込んだ既存のレスと、NG に当たったレスは出ません。最大300件）。各行の 入れる でホワイトリストに入れ、スレ でそのレスをスレタブで開けます。
  • スレ は、スレをタブで開いて全部のレスを見る画面です（OBS には出ません）。上の欄に URL を入れて Enter で開き、タブはドラッグで並べ替えられます。タブが増えると幅を縮めて画面に収め、それでも入りきらないときは2段目以降に折り返します。>>123 にマウスを乗せるとそのレスが出ます。ID をクリックすると、その ID のレスだけの表示・ホワイトリスト・NG のメニューが出ます。監視する をオンにすると、そのスレを読み上げ・OBS 表示の対象にします。
  • 開いているスレタブは、上の欄の 自動更新 で決めた間隔（10〜300秒、1秒刻み、既定15秒）ですべて自動で更新されます。今すぐ更新 で、すぐ取りに行くこともできます。同じ掲示板へは1件ずつ順に取りに行き、エラーが続いたスレは間隔を延ばします（最大300秒）。
  • スレの中の画像の URL をクリックすると、TchViewer の別ウィンドウで画像が開きます（右クリックで保存。初めて保存するときに保存先を選びます）。それ以外の URL は普段のブラウザで開きます。
  • マスク: 設定のページ（接続・Twitch イベント・ホワイトリスト・NG・読み上げ・表示（OBS）・状態・情報）では、登録スレ・Twitch チャンネル・NG・ID・フォルダの場所などを「＊＊＊」で隠しています（入力欄は ●●● になります）。配信に TchViewer の画面が映っても見えないようにするためです。見出しの横の マスク中 を押すと中身が表示され、もう一度押すと隠れます。マスクのオン・オフはページごとに保存され、次に起動したときも同じ状態になります（初めて使うときはすべてマスクしています）。Twitch にログインするときのコードも隠れるので、Twitch イベント のマスクを外してから見てください。
  • 状態 では、接続先ごとに「届いた件数」「表示した件数」「ホワイトリスト外の件数（番号だけ読んだ件数）」「NG の件数」が分かります。
  • 情報 では、画面のテーマ（Windows に合わせる／ライト／ダーク）と、画像の保存先・上限を変えられます。

10. 困ったとき

掲示板のレスが OBS に表示されない
状態 を開いて確認してください。
  • 「受信」が増えていない → スレッドの URL が正しいか、スレが埋まっていないか、監視する になっているかを確認します。
  • 「ホワイトリスト外」が増えている → その人の ID がホワイトリストに入っていません。ビュワーの下の スレの最新レス から 入れる を押してください。
  • 「NG」が増えている → NG に当たっています。
なお、表示されるのは TchViewer を起動した後に届いたレスです。それより前のレスはさかのぼって表示しません。
「ポート 11280 を開けません」と表示されて起動しない
TchViewer がすでに起動しています。タスクバーを確認してください。
OBS に何も表示されない
TchViewer が起動しているか、ブラウザソースの URL が正しいかを確認してください。表示（OBS） の テストコメント を押すと、表示を確かめられます。
Twitch のバッジが表示されない・おかしい
Twitch 側の変更で取得できなくなっている可能性があります。接続 の「Twitch のバッジ画像を取得する」をオフにしてください。
読み上げされない
テスト読み上げ で確認してください。棒読みちゃん・VOICEVOX は起動している必要があります。エラーは 状態 のログに表示されます。
不具合を報告したい
data フォルダの tchviewer.log（今回の起動分）と tchviewer.prev.log（前回の起動分）を添えてください。

11. データの場所と削除

設定などのデータは、すべて TchViewer.exe と同じフォルダの data フォルダに保存されます。Windows の AppData やレジストリには保存しません。

ファイル・フォルダ内容
config.json設定
layouts\レイアウト（見た目の設定と追加CSS。メモ帳で編集することもできます）
whitelist.jsonホワイトリスト（今日の分）
twitch-auth.binTwitch のログイン情報（暗号化。ログインしたときだけ）
ImageViewURLReplace.txt画像として開く URL の読み替え規則（LiveFake と同じ書式）
window.jsonウィンドウの位置と大きさ
badges-cache.jsonTwitch バッジの一覧（取得できなかったときの予備）
tchviewer.log / tchviewer.prev.log動作の記録（今回の起動分 / 前回の起動分）
webview\画面表示の作業データ

別のパソコンへ移すときは、フォルダごとコピーしてください。
削除するときは、TchViewer を終了してからフォルダごと削除してください。ほかの場所には何も残りません。
