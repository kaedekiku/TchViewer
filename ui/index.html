Twitch イベント

サブスク・ギフト・ビッツ・レイド・連続視聴・入力つきのチャンネルポイント報酬は、ログインしなくても表示できます。入力の無いチャンネルポイント報酬・自動報酬（メッセージのハイライトなど）・フォローを表示するには、配信者本人の Twitch アカウントでログインしてください。

Twitch にログイン（任意）

状態

ブラウザで開いた Twitch のページに、次のコードを入力して「許可」を押してください。

求める許可は読み取りだけです（チャンネルポイントの引き換え・フォロワー）。ログイン情報は Windows の機能で暗号化してデータフォルダに保存し、30日間使わないとログインし直しになります。

種類ごとの設定

読み上げる文に使える差し込み: {name} 名前 / {months} 月数 / {count} 個数・回数 / {bits} ビッツ / {viewers} 人数 / {recipient} ギフトの相手 / {reward} 報酬名 / {message} メッセージ。読み上げは「読み上げ」ページの「新着コメントを読み上げる」がオンのときだけです。
